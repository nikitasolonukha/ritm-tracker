# Ритм: правила работы

- Основной пользовательский часовой пояс: `Europe/Moscow`. Локальная дата и UTC-момент хранятся отдельно.
- Не очищать `localStorage`, IndexedDB или service worker cache во время разработки.
- Не считать плановый подход выполненным. Объем считается только по фактически подтвержденным подходам.
- Любая команда пользователя должна быть идемпотентной и иметь устойчивый идентификатор.
- Не добавлять медицинские рекомендации, неизвестные дозировки или вымышленные результаты.
- Внешние интеграции (Supabase/Telegram) считать неподключенными, пока они не проверены реальными ключами.
- После изменений запускать `pnpm test`, `pnpm lint`, `pnpm exec tsc --noEmit` и `pnpm build`.
